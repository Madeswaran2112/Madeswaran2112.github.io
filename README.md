## Deploy to GitHub Pages — recommended
Create a GitHub repository named **Madeswaran2112.github.io** and upload the contents of this folder to the `main` branch.

Then:
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions**.
4. Push the files. The included workflow will deploy the site.
5. Your portfolio URL will be:
   `https://Madeswaran2112.github.io`

GitHub's current Pages documentation recommends GitHub Actions for automated deployments.

## Alternative: Vercel
You can also import this GitHub repository into Vercel for automatic deployments, or use Vercel Drop to upload the project directly.
